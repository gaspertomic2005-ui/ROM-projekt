# Analiza globalnega segrevanja.
V projektu bom analiziral spremembe vremenskih okoliščin skozi daljše časovno obdobje. S pomočjo podatkov, ki jih bom črpal iz WeatherData, bom opazoval trende, kot so sprememba temperature in padavin. Z uporabo matematičnih metod bom te spremembe obdelal in jih bolje razumel.
